# One-time project bootstrap prompt

Use this after `agentic-init` has installed the operating layer in a real application.

> Inspect this repository once to complete the agent operating context. Read `AGENTS.md` and resolve
> every `TODO(agent)` in `docs/ai/` using manifests, configuration, code, routes, migrations, and
> tests as evidence. Keep each file concise and factual. Record only expensive-to-rediscover
> locations in the discovery index; do not create a full file inventory. Verify commands before
> documenting them, do not run destructive or externally mutating commands, and do not change
> application behavior. If intent cannot be inferred safely, leave a clearly named open decision
> instead of inventing it. Finish by running the boilerplate's `agentic-check` and report remaining
> unknowns.
